# Red Five Trench Run

A vector-graphics trench run in a single HTML file. Fly the lane, dodge the gantries, shoot the wall guns, and put a torpedo into the exhaust port at the end.

**▶ Play it: https://madd1in.github.io/trench-run/**

No build step, no dependencies, no asset files. One `index.html` — the graphics are drawn to a canvas, the music and sound effects are synthesised in the browser with the Web Audio API, and the radio chatter uses the Web Speech API with subtitles as a fallback.

## Controls

| | |
|---|---|
| `←` `↑` `↓` `→` or `WASD` | fly |
| `SPACE` | fire lasers, then torpedoes on the final approach |
| `SHIFT` | boost — faster, double score, less time to react |
| `F` | targeting computer on / off (final approach only) |
| `P` | pause |
| `SHIFT` + `F` | expand to fullscreen |

On a touchscreen: drag anywhere to fly, tap to fire.

## The run

Three sectors of increasing pressure, then a final approach.

- **Gantries and pylons** block the lane. Frames leave one opening — put the whole ship through it.
- **Wall guns** lead their shots. Two hits each and they stop.
- **TIE fighters** weave and shoot back. One ace shows up in the last sector and actively hunts you.
- **Coolant canisters** repair one point of hull. Fly through them.
- **Kill streaks** build a score multiplier up to ×5. Taking a hit resets it.
- **The exhaust port** is the whole point. Line the heading marker up with the target, hold it until the computer locks, then fire.

Or press `F`, switch the computer off, and take the shot yourself. The tolerance is wider without it, and it is worth 5,000 more points.

## Options

Difficulty (Standard / Veteran), sound, radio comms, and the bloom pass can each be toggled. Bloom turns itself off automatically if the frame rate drops below about 34 fps. Best scores are kept per difficulty in `localStorage`.

## Browser notes

- The bloom pass needs `CanvasRenderingContext2D.filter`. Where that is missing the toggle disables itself and the game renders without it.
- Speech depends on the platform's installed voices. When none are available the comms still appear as subtitles.
- Audio only starts after the first click, as browsers require.
